# TEAM-LOVELACE-BABBAGE

Eine webbasierte Reise- und Kalenderverwaltungsplattform mit Angular und Spring Boot.

---

# Features

* Kalenderverwaltung
* Tripverwaltung
* Eventverwaltung
* Import & Export von Events
* Finanzverwaltung für Kosten & Ausgaben
* Empfehlungen & Suche von Events


---

# Technologien

## Frontend

* Angular
* TypeScript
* TailwindCSS
* FullCalendar

## Backend

* Spring Boot
* Rest API
* Java 21
* Gradle

## Deployment

* Docker

---

# Projekt starten

## Frontend

```bash
cd frontend
npm install
npm start
```

Frontend läuft unter:

```txt
http://localhost:4200
```

---

## Backend

```bash
cd backend
./gradlew bootRun
```

Backend läuft unter:

```txt
http://localhost:8080
```

---

# Docker

```bash
docker compose up --build
```

---

# Tests

## Frontend (playwright)

```bash
npx playwright test
```

## Backend

```bash
./gradlew test
```
